## Core Value Proposition

<CardGrid>
  <Card title="Sensitive Data Sovereignty" icon="shield">
    <Badge text="Pillar 1" variant="note" />
    
    Complete local data privacy. Red-list species coordinates, sensitive geolocations, and unpublished field observations remain strictly on your local machine—no mandatory cloud sync or external exposure.
  </Card>

  <Card title="Zero Technical Overhead" icon="rocket">
    <Badge text="Pillar 2" variant="note" />
    
    Designed specifically for domain scientists, not software engineers. Single-click native desktop launcher requiring no environment setup, runtime management, or command-line interaction.
  </Card>

  <Card title="Automated Media & Metadata Binding" icon="document">
    <Badge text="Pillar 3" variant="note" />
    
    Seamlessly link field imagery with observation logs. Embedded EXIF spatial and temporal metadata is automatically parsed, cross-referenced, and bound into unified occurrence records.
  </Card>

  <Card title="Transparent & Verifiable Lineage" icon="list-format">
    <Badge text="Pillar 4" variant="note" />
    
    Guaranteed scientific reproducibility. Every schema mapping, unit standardization, and record modification is recorded into human-readable, machine-inspectable provenance manifests.
  </Card>

  <Card title="Domain & GIS-Aware Quality Control" icon="approve-check">
    <Badge text="Pillar 5" variant="note" />
    
    Catch spatial and biological anomalies before archiving. Automated offline sanity checks detect coordinate inversions (e.g., latitude/longitude swaps), datum shifts compatible with **QGIS** workflows, and TDWG vocabulary errors.
  </Card>

  <Card title="Turnkey FAIR Repository Deposit" icon="share">
    <Badge text="Pillar 6" variant="note" />
    
    Streamlined package generation formatted natively for global biodiversity networks (**GBIF**, **OBIS** Darwin Core Archives) and generalist data repositories (**Zenodo**, **Dryad**) to secure persistent DOIs.
  </Card>
</CardGrid>
